# ✨ Attractive & Functional Update

## 🎨 Visual Enhancements
- **Fixed Fonts**: The **Poppins** font is now correctly configured and applied throughout the app for a modern, clean look.
- **Vibrant Gradients**: Updated the header and message box with richer, more eye-catching gradients.
- **Better Shadows**: Added subtle shadows to buttons, cards, and text to give depth and a premium feel.
- **Polished UI**: Buttons now have hover effects and smoother transitions.

## 📊 New Feature: Live Vote Counter
- **Bottom Footer**: Added a stylish, floating footer at the bottom of the screen.
- **Live Count**: Shows the **Total Votes** cast in real-time.
- **Status Indicator**: Includes a pulsing "Live Voting" indicator.

## 🛠️ Authentic Structure Maintained
- Still uses the **16-row EVM layout**.
- Candidates are still positioned exactly at their serial numbers.
- Single-line names and compact rows are preserved.

### 🚀 How to Verify
1. **Run**: `npm run dev`
2. **Check Font**: Notice the clean, modern Poppins typography.
3. **Check Footer**: Look at the bottom for the "Total Votes" counter.
4. **Vote**: Cast a vote and watch the counter increment instantly!
